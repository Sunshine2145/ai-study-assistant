## CI/CD 工作流搭建

为 AI伴学系统创建了完整的 GitHub Actions CI/CD 流水线，文件位于 `.github/workflows/`：

### 创建的文件
- `.github/workflows/ci.yml` — 自动构建与测试（push/PR 触发）
  - 后端 Python 3.10 + 3.11 矩阵测试
  - flake8 代码风格检查
  - 后端健康检查（启动验证）
  - 前端静态文件检查
  - pip-audit 依赖漏洞扫描 + gitleaks 敏感信息检测
- `.github/workflows/cd.yml` — 自动部署（main push + tag 触发）
  - Staging：rsync 同步代码 + 自动重启服务
  - Production：蓝绿部署 + 自动创建 GitHub Release + 飞书通知
- `.github/workflows/pr-check.yml` — PR 快速检查
- `.github/workflows/health-check.yml` — 每日 09:00 巡检告警
- `backend/Dockerfile` — 后端容器化配置
- `backend/.dockerignore`
- `.github/CICD_SETUP.md` — 完整配置指南（Secrets/Variables 清单）

### 关键设计
- CI 不依赖真实 API Key（使用 dummy 值）
- CD 部署支持 SSH + rsync 方式，生产环境支持蓝绿切换
- 部署结果通过飞书 Webhook 通知（与现有飞书机器人集成）
