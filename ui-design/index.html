费曼讲解：指令系统

想象你在餐厅点餐：

  • 🍽️ 你 = CPU - 需要吃东西（执行任务）
  • 📋 菜单 = 指令集 - 餐厅提供的所有菜品选择
  • 👨🍳 厨师 = 硬件 - 根据菜单做菜

CISC（复杂指令集）就像一家什么菜都有的大餐厅，菜单很厚，一道菜可能包含很多步骤。

RISC（精简指令集）就像快餐店，菜单简单，每道菜都很快出炉，但需要组合多个菜品来完成一顿大餐。
