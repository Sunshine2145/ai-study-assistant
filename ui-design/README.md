## 一、设计概述

基于《AI伴学系统_PRD_v1.0.md》设计的现代化用户界面，采用**费曼学习法 + 苏格拉底提问法**作为核心交互理念，打造既美观又易用的智能备考助手界面。

### 设计目标
- ✅ **美观现代**：采用渐变、阴影、圆角等现代设计元素
- ✅ **易用直观**：清晰的信息层级和交互反馈
- ✅ **响应式设计**：适配桌面端、平板和移动端
- ✅ **品牌一致**：遵循PRD中定义的色彩规范

### 3.2 页面组成

系统包含以下6个主要页面：

#### ① 学习首页 (`#page-home`)
- **今日学习卡片**：渐变背景，显示日期、学习天数、今日任务
- **学习进度概览**：统计知识点、连续天数、积分、错题数
- **快速操作**：4个快捷入口（开始练习、复习错题、学习地图、学习报告）

#### ② 开始学习 (`#page-learn`)
- **AI对话界面**：模拟聊天形式，展示费曼讲解和苏格拉底提问
- **消息气泡**：AI消息（左侧）和用户消息（右侧）
- **费曼讲解卡片**：黄色渐变背景，突出重要概念
- **输入区域**：文本输入框 + 发送按钮 + 苏格拉底提示

#### ③ 学习地图 (`#page-map`)
- **阶段选择器**：Tab切换不同学习阶段（第一阶段~第六阶段）
- **阶段信息**：显示当前阶段名称、时间、进度条
- **知识点列表**：卡片式展示，状态包括：
  - ✅ 已完成（绿色边框）
  - 🔵 进行中（蓝色边框）
  - 🔒 未解锁（灰色+锁图标）

#### ④ 题目练习 (`#page-practice`)
- **练习头部**：显示题目类型、进度（第X题/共Y题）
- **题目卡片**：题干 + 4个选项（A/B/C/D）
- **选项交互**：点击选择 → 提交答案 → 显示正确/错误状态
- **解析卡片**：回答后显示正确答案和详细解析
- **操作按钮**：上一题、提交答案、下一题

#### ⑤ 错题本 (`#page-wrong`)
- **筛选器**：按时间筛选（本周/本月/全部）
- **错题统计**：显示错题总数
- **错题列表**：每张卡片包含：
  - 知识点标签
  - 题目内容
  - 用户错误答案（红色）
  - 正确答案（绿色）
  - 日期 + 重新练习按钮

#### ⑥ 学习报告 (`#page-report`)
- **成功提示**：大号对勾图标 + "今日任务已完成"
- **学习报告卡片**（4个）：
  - 📚 学习内容
  - ⭐ 获得积分
  - 🔥 学习连续性
  - 📅 明日预告
- **操作按钮**：分享到飞书、明天继续

## 四、交互设计

### 4.1 页面导航
- **侧边栏导航**：点击导航项切换页面，激活状态高亮显示
- **移动端适配**：小屏幕下侧边栏可收起/展开

### 4.2 题目练习流程
```
选择答案 → 点击"提交答案" → 显示正确/错误 → 显示解析 → 点击"继续下一题"
```

### 4.3 聊天交互
```
用户输入 → 点击发送/按Enter → 显示用户消息 → 1秒后AI回复 → 继续对话
```

### 4.4 反馈机制
- **Toast提示**：操作后显示简短提示（成功/错误/警告）
- **状态变化**：按钮悬停、选项选中、页面切换都有视觉反馈
- **动画效果**：淡入、滑入、缩放等微动画

## 五、响应式设计

### 5.1 断点设置
- **桌面端**：> 1024px（默认布局，侧边栏展开）
- **平板端**：768px - 1024px（侧边栏可收起）
- **移动端**：< 768px（侧边栏隐藏，顶部汉堡菜单）

### 5.2 适配策略
| 屏幕尺寸 | 侧边栏 | 网格列数 | 字体大小 |
|----------|----------|----------|----------|
| > 1024px | 固定展开 | 4列/2列 | 默认 |
| 768-1024px | 可收起 | 2列 | 默认 |
| < 768px | 隐藏 | 1列 | 略微缩小 |

## 七、设计特点

### 7.1 符合PRD要求
- ✅ 遵循PRD中定义的色彩规范
- ✅ 实现了PRD中描述的所有界面（首页、学习、地图、练习、错题、报告）
- ✅ 支持费曼讲解展示（黄色高亮卡片）
- ✅ 支持苏格拉底提问交互（提示条 + 输入框）

### 7.2 现代化设计
- **渐变背景**：首页使用品牌蓝渐变
- **卡片设计**：圆角、阴影、适当留白
- **微动画**：淡入、滑入、悬停效果
- **字体图标**：Font Awesome提供清晰图标

### 7.3 用户体验优化
- **即时反馈**：每个操作都有视觉反馈
- **清晰层级**：通过大小、颜色、间距建立信息层级
- **一致性强**：相似组件保持统一样式
- **无障碍性**：合理的对比度、可点击区域足够大
